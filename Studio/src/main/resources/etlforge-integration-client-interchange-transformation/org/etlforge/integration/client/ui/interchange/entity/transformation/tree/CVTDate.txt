<h3>Specification of the format strings:</h3>

<p>
The format of both the input date string and the output date string are specified in the same way by
using either characters for place holders or one of the four pre-defined date formats
(GeneralDate, LongDate, MediumDate, or ShortDate).
</p>
<p>
For input, year, month, day, hour, minute, second and AM/PM are read from the date string at the position where
y, m, d, H, M, S and AP appear in the input format string.
</p>
<p>
For output, the format string is copied to the data string with the year, month, day, hour, minute, and second
replacing the characters of y, m, d, H, M, S and AP.
</p>
<p>
Alternatively, the substitutions used in the ANSI C method <b>strftime</b> can be used, e.g. the string "%Y-%m-%d"
would result in the ISO 8601 date format (yyyy-mm-dd). See the unix manual page for strftime for a detailed
description (http://www.penguin-soft.com/penguin/man?q=strftime&section=ALL&action=man).
</p>
</br>
<p>
The following can appear anywhere in the format string to specify how to read the input or write the output:
</p>
</br>
</br>
