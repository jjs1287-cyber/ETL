Takes the given datetime and converts from one time zone to another.


Parameters:
fromTZ and toTZ
These time zone parameters are one of the standard TZ codes:
An abbreviation such as 'PST', or a full name such as "America/Los_Angeles", or a custom ID such as "GMT-8:00".
Note: TZ codes are case sensitive.

An unofficial list of TZ codes can currently be found here:
http://en.wikipedia.org/wiki/List_of_tz_database_time_zones

is_european_format
This optional flag causes the month and day to be swapped.
As false, the format is month then day.

ignoreDST
By default, daylight savings is accounted for when converting between the four major US time zones.
Set this optional flag to override this action.

Example:

ConvertTimeZone("02/06/2014 5:25:00", "PST", "EST"); // Returns '02/06/2014 09:25:00'
