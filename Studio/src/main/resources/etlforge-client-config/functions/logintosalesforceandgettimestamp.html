Logs in to Salesforce and retrives the current system time from Salesforce.

The login call is made using the credentials in the specified Salesforce Org. The timestamp is returned in the format yyyy-mm-dd HH:MM:SS, using your org's timezone setting by default. null is returned if either login or the call to the getServerTimestamp API fails. Use GetLastError() to get the error message in this case.

An optional second argument can be used to set the timezone to use. The timezone of your Salesforce org is used by default if a timezone is not provided.

Example:

$timestamp = LoginToSalesforceAndGetTimestamp("Salesforce Orgs/...");
if(IsNull($timestamp), RaiseError(GetLastError());

The following examples show how to specify which timezone to use:

// Get the timestamp in UTC:
$timestamp = LoginToSalesforceAndGetTimestamp("Salesforce Orgs/...", "UTC");
// Get the timestamp in Pacific Standard Time:
$timestamp = LoginToSalesforceAndGetTimestamp("Salesforce Orgs/...", "PST");

The timezone argument must be a timezone recognized by Java's TimeZone class (see http://docs.oracle.com/javase/7/docs/api/java/util/TimeZone.html).

As an alternative to this function, see GetSalesforceTimestamp().
