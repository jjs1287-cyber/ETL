This is a special function which should be called from a user defined script for text validation. It is provided so that the validation script can include the same validation as defined in text document. It takes three paramters to define the validation function. There are two required parameters: operator and argument, and third parameter ignore_case is optional with false as the default value.

Example:

If we want to validate a date in this quarter but not in the weekend, the script can looks like this

<trans>
d=Date(CvtDate(_1,_3,"yyyy-mm-dd HH:MM:SS"));
dow=DayOfWeek(d);
// formula_bulder function Validate() assume at least three input arguments are provided from the calling script
// _1(input_string), _2(data_type), _3(format) from calling script
v=Validate("=","THIS_QUARTER",false);
dow!=0 && dow!=6 && $v
</trans>
