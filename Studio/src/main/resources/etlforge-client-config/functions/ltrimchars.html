Removes all characters in the string chars from the beginning of the subject string and returns the remaining characters. Note that the subject string itself is not affected by this call.

Example:

$x = "// This is a comment"; $y = LTrimChars($x, " /") // Returns "This is a comment" In the above script, $y is assigned the value "This is a comment", whereas $x is still "// This is a comment".
