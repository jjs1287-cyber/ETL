Converts a string data element to a string representing the hexadecimal values of each char. The resulting string will be all lower-case. The result of this function call is undefined if the argument is not a string data element.

At the moment the characters in the input string must be ASCII.

This is the reverse of the function HexToString().

Example:

If $x is a string data element containing "new"
StringToHex($x) returns the string "6e6577"
