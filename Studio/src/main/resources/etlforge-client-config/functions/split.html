Splits the string str using the given delimiter. Returns the result as an array of size (number of delimiters) + 1, unless the expression ends with the delimiter in which case the size equals the number of delimiters (i.e. the last empty value is ignored). If the string contains no delimiters a vector of size 1 is returned containing the original string.

Example:

$arr=Split("Donald,Minnie,Goofy", ",");
$donald=$arr[0];
$minnie=$arr[1];
$goofy=$arr[2];
