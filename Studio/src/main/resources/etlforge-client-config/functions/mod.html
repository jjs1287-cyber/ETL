Calculates the modulus, i.e. the remainder, of the devision numerator/denominator. The return value has the same sign as the numerator. If denominator is 0 then the numerator is returned.

Example:

// This expression returns 5:
Mod(3005, 1000)

// This expression returns 0:
Mod(204, 17)

// This expression returns -2:
Mod(-206, 17)
