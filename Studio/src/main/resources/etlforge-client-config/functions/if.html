Returns true_result if condition is true, else it returns false_result. If condition is not a boolean datatype, it is converted to a boolean before it is evaluated. The third argument is optional. If it is not specified and condition is false a null value is returned.

Example:

If(false,"Jack","Diane") returns the value "Diane".
If(7>4,"Spoon","Knife") returns the value "Spoon".
If(Length($s)>0, $s=$s+",") adds "," to $s if $s is not empty.
