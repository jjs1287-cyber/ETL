Runs the specified plugin and then continues execution of the current script. The available plugins are shown in the "Plugins" tab in the lower section of the Formula Builder. When the client is connected to a ETLForge server, the plugins that are installed on that server are displayed here. Only those plugins that can be run inside a script are displayed; plugins that run on Sources, Targets, and Web Service Calls are hidden.

Returns true if the plugin completes without errors. Returns false if the plugin could not be run or the plugin implementation itself returned an error. Call GetLastError() to get the error message.
