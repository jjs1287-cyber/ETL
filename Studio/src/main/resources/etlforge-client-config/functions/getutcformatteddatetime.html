Returns a string with the UTC formatted version of the specified date and time. Replaces FromDataLoaderDateTime()
The time zone parameter should be a three character string such as: EST,CST,MST,PST,GMT, etc..
The European flag causes the month and day to be swapped. As false, the format is month then day.

Example:

FromDataLoaderDateTime("02/06/2014 19:25:00", "PST", false) // Returns 2014-02-07T03:25:00Z
