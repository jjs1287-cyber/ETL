Returns the minimum value of a data element a particular hierarchical level. It will check all instances at that level and return the smallest. It can also be called on an array to return the smalles value in that array. In that case all the values in the array have to be of the same type or the function call will fail. If the array is empty NULL is returned.

Example:

Assume your database contains a field called quantity in a table called Items that is a child of POHeader (there are many items within one POHeader).
Min(POHeader.Items#.Quantity) will return the minimum quantity for any item for a particular POHeader (purchase order).
