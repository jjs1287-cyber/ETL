Adds a specified interval of datepart to the provided datetime (Date arithmetic)


Parameters:
DatePart
A String representing the datetime part to add
This function works much like the DateAdd function in MS-SQL Server
"YY" = year, "MM" = month, "WK" = week, "DD" = day, "MI" = minute, "SS" = second

Number
Integer of the interval to add

Date
Datetime to apply add to

Example:

DateAdd("MM", 2, "08/15/2014 05:25:00"); // Returns '10/15/2014 05:25:00'
