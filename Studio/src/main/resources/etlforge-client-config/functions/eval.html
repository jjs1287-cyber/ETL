Evaluates the first argument (exp_to_evaluate). If the result is valid, the function returns the results as a string. Otherwise, the default value is returned. This can be used as a "try-catch" statement in that the second argument will be evaluated if the first one fails.

Example:

Eval(book*36.4, "Bad Entry") returns "Bad Entry"
Eval(4*25,"Bad Entry") returns a value of "100", which is the string representation of 4 multiplied by 25.
