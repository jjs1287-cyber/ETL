Returns a string in the format specified by format_str. The format specification is similar to the standard C library sprintf format specification, except for date input which accepts the same format string as the CVTDate (in the Date-Time section).

This function can also be used to "force" the output format for a target. This can be useful when the default output format that ETLForge uses for some data type (such as date or double) is not what you want. The call to Format has to be the last call in the mapping formula.

Example:

Format("%5d",2) returns the value " 2".
