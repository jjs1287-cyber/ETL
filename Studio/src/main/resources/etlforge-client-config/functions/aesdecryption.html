This function decrypts an AES encrypted string.

The first input argument is the base 64 encoded AES encrypted value.

The 2nd through 5th arguments specify the parameters to generate the key and should be the same as when AES encryption was applied. See the documentation for the AESEncryption function.

The decrypted output is a string.


Example:

encrypted = AESEncryption("Hello world!", "password");
decrypted = AESDecryption(encrypted, "password");

encrypted = AESEncryption("Hello world!", "password", "00FFAE01", 256, 1024);
decrypted = AESDecryption(encrypted, "password", "00FFAE01", 256, 1024);
