Reads a file from the specified source. The file-type source used in this function call must be defined as a source in the current integration project. The available file-type sources are shown in the "Project Items" tab in the lower section of the Formula Builder, under the node called "File Locations".

The method returns the contents of the file pointed to by the specified source. If the source filter selects more than one file, the first one will be used. It is thus recommended to specify a source that uniquely identifies only one file.

The second argument, file_name is optional and can be used to override the file name used in the source definition. Alternatively, a global data element can be used to override the file name in the source definition. Global data elements are referenced as "[de_name]" in the source definition.

This method can also be used to read data from an http source.


Example:

$file_contents = ReadFile("<TAG>Project Name/Sources/File Share Source</TAG>")
