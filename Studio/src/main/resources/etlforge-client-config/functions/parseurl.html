Parse the given url string, and return an array of decoded values. The value has a name tag, so the user can address it by the index or field name.

When retrieving the value, the case of the name is ignored.

Example:

url="http://hostname/user?email=john1990%40gmail.com&name=John%20Smith";
arr=ParseUrl(url);
email1=arr[0]; // email1 will be john1990@gmail.com
email2=arr["email"]; // same as email1
