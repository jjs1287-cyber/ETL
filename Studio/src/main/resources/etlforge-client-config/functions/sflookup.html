Logs in to Salesforce (if necessary) and retrives the result of the query from Salesforce. Only the value from the first field of the first record is returned.

The login call is made using the credentials in the specified Salesforce Org. null is returned if either login or query returns no record. API fails. Use GetLastError() to get the error message in this case.

Example:

my_id = SFLookup("<TAG>Salesforce Orgs/...</TAG>", "SELECT Id FROM Account WHERE Name='My Account'");
if(IsNull(my_id), RaiseError(GetLastError());

As an alternative to this function, see SFLookupAll() and SFLookupAllToFile().
