This function initializes a set of local variables from its argument list.
The construction of the local variable depends on two cases.

case 1. when the function call is made in the mapping of a target field.
(A call of SetInstances() function must be made privously.)
the local variable is constructed from the corresponding data element in the instance given by SetInstances() function.

case 2. when the function call is made in the script.
the local variable is constructed from the corresponding argument in the list provided by the calling runscript statement.
These veriables can be addressed also by _1, _2...

A null data element is return from this function, and should be ignored.

Example:

case 1.
Assuming in one of the parent mappings contains the following statements
...
r=DBLookupAll("<TAG>Sources/DB...</TAG>","SELECT key_name, key_value, key_type FROM key_values");
SetInstances("DETAILS",r);
...

in the "DETAILS" target node a field may have the mapping

<trans>
ArgumentList(key,value);
key+" = "+value;
</trans>

case 2.
run a script
...
RunScript("<TAG>myProject/Scripts/CalculateSomething</TAG>","John",35)
// the result value would be "John is 35 years old."
...

with the script "CalculateSomething" read as follows

<trans>
ArgumentList(name,age);
name+" is "+age+" years old."
</trans>

As an alternative to this function, see GetInstance().
