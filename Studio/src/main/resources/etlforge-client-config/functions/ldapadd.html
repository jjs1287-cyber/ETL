Adds entries and attributes to a directory. The value is added to the node specified in LdapExecute(), which should be called to make the changes take effect.

Example:

Adding a user entry to a directory:
LdapAdd("objectClass","user");
LdapAdd("cn","wright");
LdapExecute("CN=wright,CN=Users,DC=finland,DC=company,DC=com");

Adding attributes to a user:
LdapAdd("description","Thinks a lot.");
LdapExecute("CN=wright,CN=Users,DC=finland,DC=company,DC=com");
