Deletes one or more files from the specified source. The file-type source used in this function call must be defined as a source in the current integration project. The available file-type sources are shown in the "Project Items" tab in the lower section of the Formula Builder, under the node called "File Locations".

This method will delete multiple files if any found based on the file filter. An integer is returned specifying how many files were deleted. 0 means no files were found matching the file filter. If the folder cannot be found, an error will be thrown (and can be wrapped in an eval statement if needed)

The second argument, file_name is optional and can be used to override the file filter used in the source definition. Alternatively, a global data element can be used to override the file name in the source definition. Global data elements are referenced as "[de_name]" in the source definition.


Example:

DeleteFiles("<TAG>Project Name/Sources/File Source</TAG>","*.txt")
