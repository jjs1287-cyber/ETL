RunXSLT

Runs an XSLT 1.0–3.0 stylesheet against XML input. The first argument can be stylesheet text or a named project item from XSLT Transforms.

output=RunXSLT("<TAG>XSLT Transforms/Expand Embedded XML</TAG>",FileContent);
FileContent=output[0];

Returns an array with the primary result at index 0. For multiple inputs, use a start_here template and doc('param1'), doc('param2'), and so on.

Source → XSLT → Target operations run the selected stylesheet for each source file and write the primary result to the configured target. External files and network documents, stylesheet includes/imports, and xsl:result-document are not supported in this release.
