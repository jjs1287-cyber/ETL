Sends an email using the pre-configured From address, smtp servers and account. These are defined in the server configuration file. If these have not been defined you need to use one of the other email functions. The method returns a string with an error message if the email could not be sent, on success an empty string is returned.

Example:

SendSystemEmail(Get("manager_email"), "FYI", "About to process a new purchase order with POID = "
+ Get("POID") + ". Should be available for review in a few minutes.")

Example of a etlforge.conf entry for sending system emails.
[SmtpClient]
DefaultSmtpServers=mail.yourdomain.com
DefaultFromEmail=some.user@yourdomain.com
# If your smtp server needs authentication the account and password can be added here.
DefaultAccount=
DefaultAccountPassword=
