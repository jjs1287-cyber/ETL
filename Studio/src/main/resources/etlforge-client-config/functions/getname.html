returns the name of the variable. Some functions return named data element array, and GetName function let user retrieve the name of the value if it is defined.

Some of functions return the value with name:

Example 1:

x={a="var1",b="var2"};
GetName(x[0]); // return a string var1
GetName(x)[0]; // also return a string var1

values=GetSourceInstanceArray([]); // the source is a simple text and [] represent the source element
