This function checks a pair of arguments: if the first argument in the pair is true it stops checking and returns the 2nd argument with the type preserved. Otherwise it will check the next pair, and so on.

Example:

Case(price < 10, "Cheap", price < 100, "Not Cheap", price < 1000, "Expensive", true, "Very Expensive")

This expression returns "Very Expensive" if the price is 1000. true in the last argument pair serves as the default for all cases not explicitly listed.
