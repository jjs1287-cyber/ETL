Executes expression while condition is true. You can use the data element $etlforge.scripting.while.max_iterations to control how many iterations will be allowed. An error is reported if the maximum number of iterations is reached.

Example:

$etlforge.scripting.while.max_iterations = 2000;
$i=0;
// Concatenates the elements of the array $arr.
While($i<Length($arr),$s = $s + "," + Get($arr,$i); $i=$i+1)
