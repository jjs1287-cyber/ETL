Logs in to Salesforce (if necessary) and retrives the result of the query from Salesforce. The return dataelement is an array of records, and each record is an array of named-fields.

The login call is made using the credentials in the specified Salesforce Org. null is returned if either login or query returns no record. API fails. Use GetLastError() to get the error message in this case.

There are some limitations if relationship query are used.
1. only immediate relationship can be retrieved. namely query cannot include grand child relationship
2. for each query record, each child cannot have multiple records.
3. in the query statement, the fields under the same child should be grouped together.

Example 1:

records = SFLookupAll("<TAG>Salesforce Orgs/...</TAG>", "SELECT Id, Name FROM Account");
first_id=records[0][0];
first_account_name=records[0]["name"];

Example 2:

soql="SELECT Id, AccountNumber, Name, CreatedBy.ContactId, CreatedBy.FirstName, CreatedBy.LastName FROM Account";
rs=SfLookupAll("<TAG>Salesforce Orgs/feng.zheng@etlforge.invalid</TAG>",soql);
first_id=rs[0][0];
first_account_name=rs[0]["name"];
first_name=rs[0]["CreatedBy.FirstName"];
// or first_name=rs[0][4];

As an alternative to this function, see SFLookup() and SFLookupAllToFile().
