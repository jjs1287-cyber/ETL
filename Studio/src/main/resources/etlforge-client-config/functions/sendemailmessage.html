Sends an email using a pre-defined Email Message. The email message used in this function call must be defined as an Email Message in the current integration project. The available email messages are shown in the "Project Items" tab in the lower section of the Formula Builder, under the node called "Email Messages". By double clicking on an email message node, the corresponding email message ID will be inserted into the formula expression. (The ID is constructed by wrapping the project path of the selected email message within <TAG>...</TAG> tags.)

Example:

// Send a pre-defined email message.
SendEmailMessage("<TAG>MyProject/Email Messages/My Email Message<TAG>");
