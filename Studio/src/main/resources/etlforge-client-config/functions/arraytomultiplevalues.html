Signals that an array should be used to populate multiple valued LDAP attributes when mapping to an LDAP target. The array will be converted to XML and interpreted when the LDAP target is written to.

Example:

// Create two LDAP attributes using an array
$arr = Null();
Set($arr, "First instance", 0);
Set($arr, "Second instance", 1);
ArrayToMultipleValues($arr)
