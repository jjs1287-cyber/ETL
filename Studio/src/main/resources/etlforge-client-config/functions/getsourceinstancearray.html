Returns an array containing the attribute's value from an element node. The value in the array is labeled with the attribute's name, and the value in the array can be retrieved by its index or by its name as in the dictionary data element.

Example:

arr = GetSourceInstanceArray([Values$Value.]);
arr["Attr1"]; // Returns the value of the "Attr1" attribute. or
arr[0]; // if Attr1 is the name of the first attribute name

As an alternative to this function, see GetSourceInstanceMap().
