This function encrypts a string using the AES algorithm.

The first argument is the input string to encrypt.

From 2nd through 5th arguments are parameters for generating the key to encrypt. The key is generated according to Password-Based Cryptography Specification Version 2.0 (PKCS5S2).

The 2nd argument is for the password.

The optional 3rd argument is for specifying SALT parameter and, if specified, the value must be given in hex format (e.g. "A034DD").

The optional 4th argument specifies the key length. The key length must be one of 128, 192 or 256. The default is 256.

The optional 5th argument specifies the number of iterations to generate the key and the default is 1.

The encrypted output is base64 encoded. The output from AESEncryption can be passed directly to the AESDecryption function for decryption (using the same parameters as when the string was encrypted).


Example:

encrypted = AESEncryption("Hello world!", "password");
decrypted = AESDecryption(encrypted, "password");

encrypted = AESEncryption("Hello world!", "password", "00FFAE01", 256, 1024);
decrypted = AESDecryption(encrypted, "password", "00FFAE01", 256, 1024);
