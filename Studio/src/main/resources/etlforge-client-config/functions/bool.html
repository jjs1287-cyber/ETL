Converts any data type to a boolean value (true or false). If the data is an integer or floating-point number not equal to zero, the result is true (1). The strings "true" and "T" return true independently of case (i.e. "TRUE", "t" and "True" all return true). In all other cases the result is false (0).

Example:

Bool(2) returns true.
Bool("true") returns true.
Bool("F") returns false.
