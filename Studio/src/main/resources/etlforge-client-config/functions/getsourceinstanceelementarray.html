Returns an array containing the subelement's value from an element node. The value in the array is labeled with the name of the subelement, and the value in the array can be retrieved by its index or by its name as in the dictionary data element.

Example:

arr = GetSourceInstanceElementMap([Values$Value.]);
arr["e1"]; // Returns the value of the "e1" sub element. or
arr[0]; // if e1 is the name of the first sub element

As an alternative to this function, see GetSourceInstanceElementMap().
