Sets the target field to be treated as unmapped. So far this affects only database targets. The return value is null

Example:

$valueToInsert = DbLookup(....);
// If $valueToInsert is null we want to treat this field as unmapped, i.e. we do not
// want to include it in the INSERT statement that gets generated for the DB target
// for this record.
If (Length($valueToInsert) == 0, Unmap(), $valueToInsert);
