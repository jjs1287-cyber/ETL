Counts all instances of a data element at a particular hierarchical level where that data element contains a valid value (not null).

Example:

Assume your database contains a field called quantity in a table called Items that is a child of POHeader (there are many items within one POHeader).
Count(POHeader.Items#.Quantity) will return the number of item rows for a particular POHeader (purchase order) that have values in the quantity column (not null).
