Sort the array according to the some column specified in the 2nd argument.
Namely the 2nd argument specifies the index of sorting column, and the index is base 0.
The optional 3rd argument is for specifying ascending or descending order, and the default is true for ascending.
The return value is undefined and should be ignored. After the function returns, the array specified in the first argument will be sorted. Multiple columns sorting of the same array is possible by applying multiple SortArray function successively.

Example:

arr={{"a",20,1, "abc"},{"bc",7,12},{"x",20,13},{"d",5,4}};
SortArray(arr, 2, false); // sort array arr order by third column descending
SortArray(arr, 1); // sort arr order by second column ascending
arr // display result
