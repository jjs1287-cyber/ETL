This function returns the instance data element which is defined by calling SetInstances() function during the generation of the parent.

Example:

Assuming in one of the parent mappings contains the following statements
...
r1=DBLookupAll("<TAG>Sources/DB...</TAG>","SELECT key_name, key_value, key_type FROM key_values");
SetInstances("DETAILS",r1);
r2={"MS","HP"};
SetInstances("COMPANIES",r2);
...

in the "DETAILS" target node we may create a condition to have the mapping

<trans>
GetInstance()["key_value"]!="" // same as GetInstance()[0]!=""
</trans>

or, in one of the attributes, the mapping may look like

<trans>
x=GetInstance();
x["key_name"]+"="+x["key_value"] // same as x[0]+"="+x[1]
</trans>

and, in one of the attributes of "COMPANIES" target node, mapping may look like

<trans>
GetInstance() // this will return "MS" for the first instance, "HP" for 2nd
</trans>

As an alternative to this function, see ArgumentList().
