Converts a hex-string to a binary data element. The resulting data element will contain the bytes represented by each pair of characters in the input string. The input string is case-insensitive.

This is the reverse of the function BinaryToHex().

Example:

HexToBinary("17a3ef80") returns a binary data element containing the bytes 0x17 0xA3 0xEF 0x80

HexToBinary("17A3EF80") also returns a binary data element containing the bytes 0x17 0xA3 0xEF 0x80

HexToBinary("") returns an empty binary data element
