Logs in to Salesforce (if necessary) and retrives the result of the query from Salesforce to a CSV file. The function returns the number of records retrieved.

The login call is made using the credentials in the specified Salesforce Org. null is returned if either login or query returns no record. API fails. Use GetLastError() to get the error message in this case.

Example 1:

nrec = SFLookupAllToFile("<TAG>Salesforce Orgs/...</TAG>", "SELECT Id, Name FROM Account", "<TAG>Targets/...</TAG>");

Example 2:

soql="SELECT Id, AccountNumber, Name, CreatedBy.ContactId, CreatedBy.FirstName, CreatedBy.LastName FROM Account";
nrec=SfLookupAll("<TAG>Salesforce Orgs/...</TAG>", soql, "<TAG>Targets/...</TAG>");

As an alternative to this function, see SFLookup() and SFLookupAll().
