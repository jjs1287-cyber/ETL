Converts a 16 byte binary data element to a string in the standard UUID format.The resulting string will always be lower-case.

This is the reverse of the function UuidToBinary().

Example:

If $x is a binary data element containing the following 16 bytes: 0x2F 0x46 0xDA 0xD9 0xE5 0xC2 0x45 0x7E 0xB1 0xFD 0xAD 0x1B 0x49 0xB9 0x9A 0xFF
BinaryToUuid($x) returns the string "2f46dad9-e5c2-457e-b1fd-ad1b49b99aff"
