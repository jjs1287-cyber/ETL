Searches multiple instances of an element (de1) looking for the value specified in c0. If it finds it, it returns the value in the field specified in de2 for that instance. If it is not found, it returns null.

Example:

FindValue("ID",A.B#.field1,A.B.#field2) will find all the instances of B under A and check the contents of field1. It will select the first instance of A it finds where field1 contains "ID", and then return the value of field2 from that same instance.
