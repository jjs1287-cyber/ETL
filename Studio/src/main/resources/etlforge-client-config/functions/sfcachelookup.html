Logs in to Salesforce (if necessary) and retrieves the result of the query from Salesforce. Only the value from the first field of the first record is returned.
Values are cached so that subsequent calls with the same exact parameters (login and SQL) do not call Salesforce. Salesforce is only called the first time.

The login call is made using the credentials in the specified Salesforce Org. null is returned if either login or query returns no record. API fails. Use GetLastError() to get the error message in this case.

Example:

my_id = SFCacheLookup("<TAG>Salesforce Orgs/...</TAG>", "SELECT Id FROM Account WHERE Name='My Account'");
if(IsNull(my_id), RaiseError(GetLastError());
