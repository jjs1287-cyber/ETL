Converts a binary data element to a string representing the hexadecimal values of each byte. The resulting string will be all lower-case. The result of this function call is undefined if the argument is not a binary data element.

This is the reverse of the function HexToBinary().

Example:

If $x is a binary data element containing the bytes 0x17 0xA3 0xEF 0x80
BinaryToHex($x) returns the string "17a3ef80"

If $y is an empty binary data element
BinaryToHex($y) returns an empty string ("")
