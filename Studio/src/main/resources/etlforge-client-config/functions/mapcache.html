This function caches the key/value result to a dictionary. If the key already exists in the dictionary, the coresponding value will be return. Otherwise, the third argument would be evaluated as the value of the function, and the key/value would be stored in the dictionary.

Example:

d = Dict();
i=0;
$a=MapCache(d, "key1", ++i);
$b=MapCache(d, "key2", ++i);
$c=MapCache(d, "key1", ++i);
i
 The result will be 2, and $a=1, $b=2, $c=1.
