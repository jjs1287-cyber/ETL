# ETLForge test fixtures

The sample projects, SSH keys and integration fixtures in this tree are development/test data, as confirmed by the project owner. They are included with the application source. Generated result directories and the machine-specific SFTP known_hosts file are excluded.

Test code is under Server/tests and Studio/src/test. Integration tests require the documented test accounts, directories and servers; compilation and local smoke tests do not require running those integrations.
